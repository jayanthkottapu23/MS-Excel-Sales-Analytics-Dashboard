# MS-Excel-Sales-Analytics-Dashboard

📌 Project Overview

An interactive MS Excel dashboard developed to analyze and visualize sales and shipment performance, providing key insights into profitability, regional performance, customer segments, shipment trends, order priorities, packing efficiency, and overall sales performance.

### 🎯 Objectives

* Clean and prepare raw sales and shipment data for analysis
* Remove blank records, spelling errors, and unwanted spaces
* Transform and enrich data using VLOOKUP and Excel functions
* Create calculated columns for dates, day types, and other metrics
* Analyze sales, profit, shipment, and customer-related data
* Design an interactive dashboard using slicers, charts, and visualizations
* Present key business insights through an executive-level dashboard

### 🛠️ Tools Used

* Microsoft Excel
* Excel Functions
* Pivot Tables
* Slicers & Charts

### 📊 Data Analysis & Dashboard Operations Performed

* **Data Cleaning & Preparation** – Cleaned and prepared the dataset by removing blank records, unwanted spaces, and data inconsistencies.
* **Data Transformation & Enrichment** – Transformed and enhanced the dataset by creating additional columns and deriving meaningful information.
* **Sales & Profit Analysis** – Analyzed sales and profit performance across regions, customer segments, and different time periods.
* **Shipment & Order Analysis** – Analyzed shipment modes, order priorities, and day types to understand shipment and order performance.
* **Trend & Performance Analysis** – Analyzed daily sales trends, packing efficiency, and yearly sales performance.
* **Interactive Dashboard** – Developed an interactive dashboard using slicers, charts, and visualizations to present key business insights.
